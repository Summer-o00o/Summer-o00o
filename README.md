# Hi, I'm Summer Wang 👋

I'm a software developer based in Seattle, WA, with a background in biomedical research.

I took a nontraditional path into software engineering. While working in a research lab, I started teaching myself programming to automate repetitive workflows and build tools for the people around me. What started with Python scripts and a Java desktop application eventually led me to full-stack development, cloud infrastructure, AI, and graduate study in computer science.

I'm currently pursuing an M.S. in Computer Science at Georgia Tech and continuing to learn by building projects, experimenting with new technologies, and participating in hackathons.

### Private Pet Vaccine Pass
**MLH × Midnight Hackathon — August 2026**

A privacy-preserving application that uses zero-knowledge proofs to verify a pet's vaccination status without exposing the underlying medical record.

- Built two React/TypeScript PWA experiences for pet owners and verifiers
- Designed QR-based credential and verification flows
- Implemented proof logic with Midnight Compact
- Integrated Midnight SDKs for credential, wallet, and proof workflows
- Designed verification so a verifier can confirm vaccination coverage without receiving the pet's full private record

### In-Browser Alt Text Generator

A browser-based accessibility project that runs multimodal inference locally without requiring a backend.

- Built with Vite, TypeScript, and Hugging Face Transformers
- Used `SmolVLM-256M-Instruct` to generate image descriptions directly in the browser
- Added a `SmolLM2-360M-Instruct` rewrite loop to produce shorter alt text
- Exposed the generation process so users can inspect the initial output and rewrite passes
- Used WebGPU when available with a WASM fallback for broader browser compatibility

## My Story

Before software engineering, I spent several years working in biomedical research, including ovarian cancer research.

My primary work was hands-on laboratory research, but I became interested in programming after noticing repetitive processes that could be improved with software. Alongside my research responsibilities, I taught myself Python and Java and started building tools for the lab.

- A Python automation tool reduced routine data-processing time by about **50%**
- A Java GUI for specimen records improved data-entry turnaround by about **30%**

Those projects changed the direction of my career. I enjoyed being able to identify a practical problem, build something, and see the result immediately.

Since then, I've continued moving deeper into software engineering through graduate study, independent projects, cloud and full-stack development, and hackathons.
